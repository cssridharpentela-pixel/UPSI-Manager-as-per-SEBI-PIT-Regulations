Backup and restore

This register is stored in this browser only. Download a backup regularly and keep it as the auditor’s copy. Regulation 3(6) requires preservation for at least eight years after the transaction is complete, or until any SEBI proceeding ends.

Restore only works into an empty register, and only if the backup’s chain verifies.

Time stamps use this device’s clock. For a stronger audit position, run this file on an internal server with a controlled clock, since the regulation expects the database to be maintained internally and not outsourced.
